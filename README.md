# Booking — Сервис бронирования

Данный проект представлят собой учебный проект в рамках которого развивабтся навыки fullstack разработки.

## Проблемы которые решает сервис
- **Бронирование** — комнат, студии, квартир и технических помищении.
- **Анализ** — Определение статистики и сбор данных о предпочтениях пользователй.
- **Администрирование** — Полный комплект GUI инструментов в web формате. Инструменты позволяют управлять проектом без знании в технической области.


## Стек технологии
- **Backend:** Node.js, Express.js
- **База данных:** PostgreSQL, pg (node-postgres)
- **Аутентификация:** JWT (JSON Web Tokens), bcryptjs
- **Контейнеризация:** Docker, Docker Compose
- **Тестирование и качество:** Jest, ESLint, Prettier, Husky, Lint-staged
- **Frontend:** Vanilla JS, HTML5, CSS3 


## Быстрый старт
### 1. Запуск через Docker Compose (рекомендуется)
Убедитесь что у вас установлен Docker и Docker Compose.

1. Клонируйте репазитории с gitHub:
```bash
git clone https://github.com/Kirossic/Bookings.git
cd Bookings
```

2. Запуск проекта:
```bash
docker compose up --build
```

После выпонения таких простых действий вы спожете перейти по адресу: `http://localhost:3000`

### 2. Ручной запуск
Для выполнения ручного запуска вам нужно подготовить своё окружение(установка PostgreSQL и Node.js) и так же настроить установленые инструменты, после чего вы можете:

1. Установить зависимости:
```bash
npm install
```

2. Примени миграции БД:
```bash
npm run migrate
```
3. Запусти сервер в режиме разработки:
```bash
npm run dev
```

В терменале будент выведена подробная информация и навигация.

## Доступные npm-скрипты
Так же предлогаю вам ознакомиться с скриптами проекта:
- `npm run dev` — запуск бэкенда с перезапуском при изменениях (nodemon)
- `npm run migrate` — выполнение миграций базы данных
- `npm test` — запуск тестов (Jest)
- `npm run lint` — проверка качества кода (ESLint)
- `npm run format` — форматирование кода (Prettier)

## Структура проекта
- `backend/` — исходный код API, контроллеры, маршруты и middleware
- `db/` — скрипты миграций и подключение к PostgreSQL
- `public/` — статические файлы фронтенда (HTML, CSS, клиентский JS)
