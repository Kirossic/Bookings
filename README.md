# Booking — Сервис бронирования

Данный проект представляет собой учебный проект, в рамках которого развиваются навыки fullstack разработки.

## Проблемы, которые решает сервис
- **Бронирование** — комнат, студий, квартир и технических помещений.
- **Анализ** — Определение статистики и сбор данных о предпочтениях пользователей.
- **Администрирование** — Полный комплект GUI инструментов в web формате. Инструменты позволяют управлять проектом без знаний в технической области.


## Стек технологий
- **Backend:** Node.js, Express.js
- **База данных:** PostgreSQL, pg (node-postgres)
- **Аутентификация:** JWT (JSON Web Tokens), bcryptjs
- **Контейнеризация:** Docker, Docker Compose
- **Тестирование и качество:** Jest, ESLint, Prettier, Husky, Lint-staged
- **Frontend:** Vanilla JS, HTML5, CSS3 


## Быстрый старт
### 1. Запуск через Docker Compose (рекомендуется)
Убедитесь, что у вас установлен Docker и Docker Compose.

1. Клонируйте репозиторий с GitHub:
```bash
git clone https://github.com/Kirossic/Bookings.git
cd Bookings
```

2. Запуск проекта:
```bash
docker compose up --build
```

После выполнения таких простых действий вы сможете перейти по адресу: `http://localhost:3000`

### 2. Ручной запуск
Для выполнения ручного запуска вам нужно подготовить своё окружение (установка PostgreSQL и Node.js) и также настроить установленные инструменты, после чего вы можете:

1. Установить зависимости:
```bash
npm install
```

2. Применить миграции БД:
```bash
npm run migrate
```
3. Запустить сервер в режиме разработки:
```bash
npm run dev
```

В терминале будет выведена подробная информация и навигация.

## Доступные npm-скрипты
Также предлагаю вам ознакомиться со скриптами проекта:
- `npm run dev` — запуск бэкенда с перезапуском при изменениях (nodemon)
- `npm run migrate` — выполнение миграций базы данных
- `npm test` — запуск тестов (Jest)
- `npm run lint` — проверка качества кода (ESLint)
- `npm run format` — форматирование кода (Prettier)

## Структура проекта
- `backend/` — исходный код API, контроллеры, маршруты и middleware
- `db/` — скрипты миграций и подключение к PostgreSQL
- `public/` — статические файлы фронтенда (HTML, CSS, клиентский JS)
