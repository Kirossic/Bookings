## ⚠️ Что нужно сделать ВЛАДЕЛЬЦУ РЕПОЗИТОРИЯ

### КРИТИЧЕСКИ ВАЖНО: Очистка истории Git

Старый пароль "m080603m" всё ещё находится в истории Git и может быть извлечен командами:
```bash
git log --all -S "m080603m"
git show <commit-hash>:db_local/db.js
```

**Необходимые действия:**

1. **Прочитайте `DOC/SECURITY_PASSWORD_CLEANUP.md`** - полное руководство
2. **Выберите метод очистки:**
   - BFG Repo-Cleaner (рекомендуется, быстро)
   - git-filter-repo (современный)
   - git-filter-branch (медленный, устаревший)
3. **Создайте резервную копию** репозитория
4. **Сообщите команде** о предстоящем force push
5. **Выполните очистку** согласно инструкциям
6. **Принудительно отправьте изменения** (git push --force)
7. **Сообщите всем переклонировать** репозиторий

### КРИТИЧЕСКИ ВАЖНО: Смена пароля в базе данных

Если пароль "m080603m" использовался для реальной базы данных:

1. **НЕМЕДЛЕННО** смените пароль в PostgreSQL:
   ```sql
   ALTER USER postgres WITH PASSWORD 'новый_безопасный_пароль';
   ```

2. **Обновите** файл `.env` на сервере:
   ```bash
   DB_PASSWORD=новый_безопасный_пароль
   ```

3. **Перезапустите** приложение
